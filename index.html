Write to the Base layer?

      
Base is the keyboard's safe fallback layer. GK6XPlus never changes it, so it still holds the factory layout
        you can return to if Layers 1–3 go wrong.

      
Editing it is best avoided. If you do, keep the letters and a way to switch layers.
